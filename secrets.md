# 🔐 Configuração de Secrets

## Serper.dev (API de busca Google)
1. Acesse: https://serper.dev
2. Crie conta gratuita (2.500 buscas/mês)
3. Copie a API Key
4. No GitHub: Settings → Secrets → New repository secret
5. Nome: `SERPER_API_KEY`
6. Valor: cole sua chave

## Pexels API (imagens - opcional)
1. Acesse: https://www.pexels.com/api/
2. Crie chave gratuita
3. Adicione como `PEXELS_API_KEY` no GitHub (usado no script JS do artigo)
